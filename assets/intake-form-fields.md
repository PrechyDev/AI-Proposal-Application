# Proposal Intake Fields

Use these fields as the reference intake structure for the proposal application. Students may keep the same fields, rename them, or add fields if their application needs more context.

Original reference form: https://forms.gle/5GXAVU92sqJf3EAKA

## Fields

| Field | Suggested Key | Notes |
| --- | --- | --- |
| Client Name | `client_name` | Name of the client contact. |
| Client Email | `client_email` | Email address for client delivery. |
| Company Name | `company_name` | Client company or organization. |
| Date of Call | `date_of_call` | Date the sales or discovery call happened. |
| Salesperson Name | `salesperson_name` | Person preparing or owning the proposal. |
| Summary of Client's Needs | `client_needs_summary` | The problem the client wants to solve. |
| Project Scope | `project_scope` | What the client wants built or delivered. |
| Goals and Objectives | `goals_and_objectives` | The outcomes the client wants, such as revenue growth, efficiency, or reduced manual work. |
| Recommended Services or Deliverables | `recommended_services` | The proposed services, outputs, or deliverables. |
| Proposed Timeline | `proposed_timeline` | Expected duration, phases, or delivery window. |
| Estimated Pricing | `estimated_pricing` | Proposed price, range, or pricing notes. |
